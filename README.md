# 🎓 Academic Dashboard (`v2.3.4`)

**לוח בקרה אקדמי אישי, חכם ואינטראקטיבי לניהול הסמסטר, מטלות, יחידות לימוד ומפגשים.**

המערכת נבנתה במיוחד עבור סטודנטים כדי לרכז את כל המידע הלימודי במקום אחד ברור, נקי ונגיש, עם מעקב אוטומטי אחר קצב הלימוד, סנכרון קל בין מכשירים ושיתוף קבצי קורסים בין סטודנטים.

## ✨ פיצ'רים מרכזיים

* **📋 המשימות שלך לשבוע הקרוב (Smart Weekly Tasks):**
  * תצוגה מתכווצת בראש הדאשבורד המרכזת אוטומטית את סדרי העדיפויות שלך:
    1. **יחידות לימוד בפיגור בקצב** (כולל חישוב מדויק של שבועות האיחור).
    2. **מטלות להגשה בשבוע הקרוב** (טווח של 7 ימים קדימה, כולל התראה בולטת על מטלות שעבר מועד הגשתן).
    3. **יחידות לימוד שזמן הלימוד המומלץ שלהן מסתיים השבוע.**

* **📅 לו"ז שבועי מאוחד (Unified Schedule):**
  * תצוגת 7 ימים לכל הקורסים במקביל עם **הפרדה מפלסית** ברורה בין מפלס המטלות למפלס המפגשים.
  * סימון הגשת מטלות ונוכחות במפגשים בלחיצה אחת, כולל חיווי אוטומטי למפגשים שחלפו.

* **📚 ניהול קורסים ומעקב התקדמות (QuickView & Course Dashboard):**
  * כרטיסיית סקירה מהירה לכל קורס המציגה אחוזי התקדמות ביחידות הלימוד, צבירת נקודות חובה במטלות, יחידת הלימוד הנוכחית, המפגש הבא, המטלה הבאה וקישורים מהירים.
  * **דף קורס ייעודי:** גרפי סטטוס (Donut Charts) למטלות ולנוכחות, מחשבון ציון משוקלל בזמן אמת, וניהול מלא של יחידות, מטלות, מפגשים וקישורים.

* **🔗 סנכרון בין מכשירים בלחיצת כפתור (Cross-Device Sync Link):**
  * לחיצה על **"העתקת לינק לסנכרון"** בראש העמוד דוחסת ומקודדת את כל מצב המערכת (קורסים, התקדמות וערכת נושא) לתוך קישור מאובטח.
  * שליחת הקישור (למשל בוואטסאפ) ופתיחתו במכשיר אחר טוענת אוטומטית את כל הנתונים ללא צורך בהרשמה או בשרת חיצוני.

* **📅 הגדרת תאריכי סמסטר דינמית:** התאמה אישית של תאריך תחילת הסמסטר (שבוע 1) ותאריך סיום הסמסטר (עם ברירת מחדל מובנית לתאריכי האוניברסיטה הפתוחה: `25/10/2026 – 31/01/2027`), המייצרת אוטומטית את שבועות הלימוד בלו"ז ומסנכרנת את מעקב הקצב מול השבוע הנוכחי.

* **🔄 שיתוף קורסים בקבצי JSON:**
  * אפשרות לייצא כל קורס לקובץ `.json` בודד ולשתף אותו עם חברים לספסל הלימודים.
  * סטודנט אחר יכול לטעון את הקובץ בלחיצה אחת ולקבל את כל המפגשים, המטלות ויחידות הלימוד של הקורס מוכנים מראש!

* **🎨 התאמה אישית מלאה (Color Schemes):**
  * בחירה בין 6 ערכות צבעים מעוצבות (Dark Slate, Royal Indigo, Sunset Rose, Emerald Mint, Purple Amethyst, Amber Dusk).

* **🔒 פרטיות מלאה (100% Client-Side):**
  * המערכת פועלת כקובץ HTML יחיד ללא צורך בשרת או בהרשמה. כל הנתונים נשמרים מקומית בדפדפן (`LocalStorage`), עם אפשרות לגיבוי ושחזור מלאים בכל עת.

## 🚀 איך מתחילים?

המערכת פועלת לחלוטין בצד הלקוח ושומרת את כל הנתונים שלך מקומית ופרטית בדפדפן (`LocalStorage`). ניתן להשתמש בה באחת משתי דרכים:

### אפשרות א': שימוש ישיר אונליין (מומלץ)
אין צורך בהורדה או בהתקנה — פשוט נכנסים לקישור ומתחילים לעבוד:
👉 **[כניסה למערכת](https://klempor.github.io/academic-dashboard/)**

### אפשרות ב': הרצה לוקאלית מהמחשב (ללא צורך באינטרנט)
1. הורידו את הקובץ `index.html` למחשב שלכם (או לחצו על **Code** ➡️ **Download ZIP** וחלצו את התיקייה).
2. לחצו לחיצה כפולה על הקובץ `index.html` כדי לפתוח אותו בכל דפדפן מודרני (Chrome, Edge, Safari, Firefox).

> 💡 **מעבר בין מכשירים (מחשב ⇄ נייד):** לחצו על כפתור **"העתקת לינק לסנכרון"** בסרגל העליון, שלחו לעצמכם את הקישור שהועתק (למשל בוואטסאפ), ופתחו אותו במכשיר היעד כדי לטעון מיד את כל הנתונים העדכניים.

## 🤝 מאגר קורסים משותף ותרומה לקהילה

במאגר קיימת תיקיית `courses/` המחולקת לפי **אוניברסיטה ➡️ קורס ➡️ קבוצת לימוד**, בה סטודנטים משתפים קבצי `.json` מוכנים לסמסטר.  
רוצים להוסיף את הקורס וקבוצת הלימוד שלכם כדי לעזור לסטודנטים אחרים? קראו את מדריך התרומה המלא בקובץ **[CONTRIBUTING.md](CONTRIBUTING.md)**.
